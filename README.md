## ✨ About

A random password generator I built to practice the core React hooks. The password regenerates whenever an option changes, and one click copies it to the clipboard.

## 🔋 Features

- 🎚️ Length slider
- 🔢 Toggle numbers and ✳️ special characters
- ⚡ Regenerates automatically when options change (`useEffect`)
- 📋 Copy to clipboard, with the field selected via `useRef`
- 🧠 Memoized generator with `useCallback`

## 🛠️ Tech stack

React 18 · Vite · Tailwind CSS · Hooks: `useState`, `useCallback`, `useEffect`, `useRef`

## 🚀 Getting started

```bash
git clone https://github.com/ahmadtahir1399/react-password-generator.git
cd react-password-generator
npm install
npm run dev
```
